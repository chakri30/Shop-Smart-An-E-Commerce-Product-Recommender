#Shop Smart an E-Commerce Product Recommender

**Hybrid Recommendation System + LLM-Powered Explanations**

---

## Objective
Combine recommendation logic with **LLM-generated explanations** for users.

---

## Features
- User registration & login
- Search products
- Content-based recommendations
- **LLM-powered "Why this product?" explanations** (unique per product)
- REST API
- Responsive UI with Bootstrap 5

---

## Tech Stack
- Flask
- SQLite
- Pandas + Scikit-learn
- Hugging Face Transformers (DistilGPT2)

---
